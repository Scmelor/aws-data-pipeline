# AWS Data Pipeline — Digital Wallet Transactions

![CI](https://github.com/Scmelor/aws-data-pipeline/actions/workflows/ci.yml/badge.svg)

End-to-end data engineering project: ingestion, cleaning and modeling of digital-wallet transactions with **PySpark**, deployed on **AWS (S3 · Glue · Crawlers · Athena)**, provisioned with **Terraform**, orchestrated with **Airflow** and visualized in **QuickSight**.

> Data is **synthetic** (generated by `scripts/generate_data.py`) and intentionally includes quality issues: duplicates, nulls, negative amounts, mixed date formats and inconsistent categories.

## Architecture

```
generate_data.py ──► S3 raw/ (CSV)
                         │
                 Glue ETL Job (PySpark)  ◄── orchestrated by Airflow
                         │
          ┌──────────────┴──────────────┐
   S3 clean/ (Parquet,             S3 curated/ (daily KPIs)
   partitioned by event_date)            │
          └──────► Glue Crawler ◄────────┘
                         │
                  Glue Data Catalog ──► Athena (SQL) ──► QuickSight
```

## Repository layout

| Path | Purpose |
|---|---|
| `src/jobs/transform.py` | Reusable PySpark transformations (clean, KPIs, quality report) |
| `src/jobs/run_local.py` | Runs the full pipeline locally |
| `glue/glue_job.py` | Same logic packaged as an AWS Glue job |
| `infra/terraform/` | S3 lake, Glue database/crawler/job, IAM role, Athena workgroup |
| `dags/` | Airflow DAG: extract → transform → quality check |
| `sql/athena_queries.sql` | Analytical queries over the catalog |
| `tests/` | PySpark unit tests (pytest) |
| `.github/workflows/ci.yml` | Lint + tests on every push |

## Run locally

Requires Python 3.11 and Java 17.

```bash
make install   # dependencies
make test      # unit tests
make run       # generate data + run pipeline -> data/clean, data/curated
make docker    # same, inside Docker
```

## Deploy to AWS

```bash
cd infra/terraform && terraform init && terraform apply
cd ../.. && bash scripts/upload_to_s3.sh $(terraform -chdir=infra/terraform output -raw lake_bucket)
aws glue start-job-run --job-name scmelor-data-pipeline-etl
aws glue start-crawler --name scmelor-data-pipeline-clean-crawler
# then query in Athena with sql/athena_queries.sql
terraform -chdir=infra/terraform destroy   # avoid costs
```

## Data quality rules

1. Deduplicate on `transaction_id`.
2. Parse two timestamp formats; drop unparseable rows.
3. Drop null or non-positive amounts.
4. Normalize `channel` (trim + lowercase) and keep only the valid catalog.
5. Each run logs raw/clean row counts and % dropped.
